# expo-ble-kit example app

This app exercises the `expo-ble-kit` library in the parent directory. Read `../AGENTS.md` and `../docs/ARCHITECTURE_AND_PLAN.md` first.

- `expo-ble-kit` resolves to `..` through `metro.config.js` (`extraNodeModules`) and `tsconfig.json` (`paths`). Run `yarn prepare` in the repo root after changing library code that the app imports from `build/`.
- The library's config plugin is applied from `app.json` as `../app.plugin.js`.
- `ios/` and `android/` are generated by `npx expo prebuild` (Continuous Native Generation) and gitignored. Never edit them by hand; change the config plugin instead.
- Install packages with `npx expo install <package>` so versions match the Expo SDK.
- There is no router. Example screens planned in §7 (Explorer, Heart Rate, Phone-as-Peripheral, Throughput, Background) are added as plain components until a navigation library is chosen.
- Bluetooth does not work in the iOS Simulator. BLE behavior on iOS is only verified on devices (plan §8.1).
