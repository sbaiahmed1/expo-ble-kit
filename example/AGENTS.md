# expo-ble-kit example app

This app exercises the `expo-ble-kit` library in the parent directory. Read `../AGENTS.md` and `../docs/ARCHITECTURE_AND_PLAN.md` first.

- `expo-ble-kit` resolves to `..` through `metro.config.js` (`extraNodeModules`) and `tsconfig.json` (`paths`). Run `yarn prepare` in the repo root after changing library code that the app imports from `build/`.
- The library's config plugin is applied from `app.json` as `../app.plugin.js`.
- `expo-build-properties` with `ios.enableSceneSupport: true` is required while the example is on SDK 57: without the UIScene life cycle, builds made with Xcode 27 crash at launch on iOS 27. Remove it when moving to SDK 58. It belongs to the example only, never to the library.
- `ios/` and `android/` are generated by `npx expo prebuild` (Continuous Native Generation) and gitignored. Never edit them by hand; change the config plugin instead.
- Install packages with `npx expo install <package>` so versions match the Expo SDK.
- There is no router. Example screens planned in §7 (Explorer, Heart Rate, Phone-as-Peripheral, Throughput, Background) are added as plain components until a navigation library is chosen: `App.tsx` switches tabs between the screens in `src/screens/`.
- Demo mode (the switch in the header) installs the fake adapter with five test peripherals built from `test-peripherals/profile.json` (`BleKit-Test`, `BleKit-Test-2`…; `src/demo/testPeripheral.ts`), so the screens, their Jest tests and the Maestro flows (`e2e/maestro/`) run without hardware. Leaving it needs an app restart.
- `yarn test` runs the screens' Jest tests against the fake. Jest maps `expo-ble-kit` to `../src` and forces one copy of `react`, `react-native` and `expo` (the example's).
- The Heart Rate screen stays connected with `connect({ reconnect })` (P2-01). The developer checks' sink buttons (`src/lib/sink.ts`) are the acceptance runs of P2-02 and P2-03 against the test peripheral.
- Bluetooth does not work in the iOS Simulator. BLE behavior on iOS is only verified on devices (plan §8.1).
